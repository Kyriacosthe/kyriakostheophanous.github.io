# Kyriakos Theophanous Basketball Analytics Portfolio

Static portfolio website for basketball analytics reports, methodology notes, and NCAA team/player analysis.

## Public Site Files

- `index.html`
- `article.html`
- `styles.css`
- `script.js`
- `article.js`
- `content/site-data.json`
- `assets/`

The site is designed for GitHub Pages and does not require a backend.

## Content Updates

Content is driven by `content/site-data.json`. The local admin/CMS tools are kept out of this public repository and should be used locally before committing the updated public files.

## Contact Form

The contact form uses `mailto:` so it works on static hosting. Submitting the form opens the visitor's default email app with a prefilled message.
